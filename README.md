# r08-access-bridge-releases

Release binaries for a personal fork of [R08 Access Bridge](https://github.com/Anezium/R08-Access-Bridge) by [Anezium](https://github.com/Anezium).

This is a modified version of the upstream project; fork builds carry a "+pN" suffix in their version names. Code lives in a separate private repository; this repo hosts release APKs only.
